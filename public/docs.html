Authentication Endpoints

POST /api/auth/register

Description: Register a new user account

Request Body:

{
  "username": "string",
  "password": "string"
}

Response:

{
  "id": "uuid",
  "username": "string"
}
POST /api/auth/login

Description: Login and receive JWT tokens + encryption salt

Request Body:

{
  "username": "string",
  "password": "string"
}

Response:

{
  "accessToken": "jwt_token",
  "refreshToken": "uuid",
  "encryption_salt": "hex_string"
}
POST /api/auth/token

Description: Refresh access token using refresh token

Request Body:

{
  "refreshToken": "uuid"
}

Response:

{
  "accessToken": "new_jwt_token"
}
POST /api/auth/logout

Description: Invalidate refresh token (logout)

Request Body:

{
  "refreshToken": "uuid"
}

Response:

{
  "ok": true
}

Password Entry Endpoints

POST /api/entries

Description: Create a new encrypted password entry

Headers: Authorization: Bearer {accessToken}

Request Body:

{
  "name": "string",
  "ciphertext": "base64_encrypted_password",
  "iv": "base64_initialization_vector",
  "tag": "base64_auth_tag",
  "meta": { "url": "string (optional)" }
}

Response:

{
  "ok": true
}
GET /api/entries

Description: List all password entries for authenticated user

Headers: Authorization: Bearer {accessToken}

Response:

{
  "entries": [
    {
      "id": "uuid",
      "name": "string",
      "ciphertext": "base64_string",
      "iv": "base64_string",
      "tag": "base64_string",
      "meta": { "url": "string" },
      "created_at": "timestamp"
    }
  ]
}

Example Usage (cURL)

Register a User

curl -X POST http://localhost:4000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"alice","password":"SecurePass123!"}'

Login

curl -X POST http://localhost:4000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"alice","password":"SecurePass123!"}'

List Entries

curl http://localhost:4000/api/entries \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"

Security Notes

  • Zero-Knowledge: The server never sees plaintext passwords. All encryption must happen client-side.
  • Encryption Key Derivation: Use the encryption_salt from login with the master password to derive the AES-256 key.
  • Rate Limiting: Auth endpoints are limited to 10 requests per 15 minutes per IP.
  • Token Expiry: Access tokens expire in 15 minutes. Use refresh token to get new access token.
